# htmlAnalyzer

A lightweight Java HTML analyzer/parser built **without external libraries or frameworks** (pure JDK).  
Inspired by a job interview challenge — this project expands on that exercise with improved capabilities, flexibility, and extensibility.

---

## 🔍 Overview

`htmlAnalyzer` is a Java-based HTML parser that analyzes the structure and content of HTML documents.  
Unlike typical solutions (e.g., Jsoup), this project does **not** rely on third-party libraries — it is implemented using only core Java features.

The goal is to provide a **better understanding of HTML parsing logic** and demonstrate strong Java programming skills.

---

## 🧠 Features

- ✅ Parses HTML input from files or text
- ✅ Extracts and analyzes tags, attributes, and text content
- ✅ Supports nested elements
- ✅ Detects malformed HTML
- 🛠 Designed to be extensible for additional analysis use cases
- 📚 Pure Java (no external dependencies)

Example use cases:

- Counting number of elements
- Extracting full html or specific segments
- Validating HTML format

---

## 🚀 Motivation

This project was born from a **job interview challenge**:  
> *Analyze an HTML document without using third-party libraries such as jsoup.*

While the original code was functional, I wanted to go further — not only solving the interview task but expanding and improving it as a personal project to:

- Deepen my understanding of **Java parsing**
- Practice building a reusable tool without shortcuts
- Showcase clean design, modularity, and algorithmic thinking
